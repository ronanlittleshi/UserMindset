# 抖小保 - 平台保障助手 Demo

这是一个完整的可交互前端 Demo，展示了抖小保智能助手的功能。

## 📦 文件说明

### 核心文件
- `index.html` - 主页面文件（完整功能，包含后端API接入）
- `index-offline.html` - 离线版本（仅使用前端逻辑，不需要后端服务器）
- `server.js` - Node.js后端服务器
- `package.json` - 项目依赖配置
- `.env` - 环境变量配置（包含API密钥）

### 资源文件
- `抖小保.png` - 抖小保头像
- `Feed刷广告.mp4` - 背景视频
- `转化记录列表页.png` - 转化记录页面截图
- `客服页面.jpg` - 客服页面截图
- `feed广告图.jpg` - 备用广告图片

## 🚀 快速开始

### 方式一：完整版本（推荐）
需要Node.js环境，接入火山引擎API

```bash
# 1. 安装依赖
npm install

# 2. 启动后端服务器
npm start

# 3. 在另一个终端启动前端服务器
python3 -m http.server 8080

# 4. 打开浏览器访问
http://localhost:8080
```

### 方式二：离线版本
不需要后端服务器，仅使用前端逻辑

```bash
# 1. 启动前端服务器
python3 -m http.server 8080

# 2. 打开浏览器访问
http://localhost:8080/index-offline.html
```

## 🎯 功能说明

### 1. 抖小保浮窗
- 仅在广告时间段内显示
- 自动抖动并弹出气泡提醒
- 点击可打开"猜你想问"面板

### 2. 猜你想问
提供预设问题快速提问：
- 平台能为我提供哪些保障？
- 遇到问题平台会怎么处理？
- 消费后出现纠纷怎么办？
- 平台如何保障我的权益？

### 3. 智能对话
- 广告记录查询及跳转
- 客服位置查询及跳转
- 生活问题解答
- 广告相关问题解答
- 上下文感知（记住之前的问题）

### 4. 页面跳转
- 转化记录页面
- 客服页面

### 5. 视频控制
- 播放/暂停背景视频

## 🔧 配置说明

### API配置
在 `.env` 文件中配置火山引擎API密钥：
```
API_KEY=你的API密钥
```

### 广告时间段配置
在 `index.html` 中修改 `adTimeRanges` 数组：
```javascript
const adTimeRanges = [
    { start: 1, end: 4.5 },  // 第1-4.5秒显示抖小保
    { start: 7.5, end: 10.5 } // 第7.5-10.5秒显示抖小保
];
```

## 💡 使用场景

### 测试广告记录查询流程
1. 等待视频播放到广告时间段
2. 点击抖小保打开"猜你想问"
3. 点击"平台能为我提供哪些保障？"
4. 在对话框中输入"广告记录在哪里？"
5. 输入"找不到"
6. 点击"点击查看广告记录"按钮

### 测试客服查询流程
1. 点击抖小保打开"猜你想问"
2. 在对话框中输入"客服在哪里？"
3. 输入"找不到"
4. 点击"点击联系客服"按钮

## 📝 注意事项

1. **视频播放**：首次加载视频可能需要一些时间，请耐心等待
2. **API调用**：完整版本需要有效的火山引擎API密钥
3. **浏览器兼容性**：建议使用最新版本的Chrome、Safari或Edge浏览器
4. **文件路径**：确保所有资源文件与HTML文件在同一目录下

## 🔍 调试技巧

如果遇到问题，可以：
1. 打开浏览器开发者工具（F12）
2. 查看Console标签页的错误信息
3. 检查Network标签页的API调用状态
4. 确认后端服务器是否正常运行
